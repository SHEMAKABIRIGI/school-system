# School Data Management System

Secondary school website with a staff data management system.

Stack: HTML, CSS (responsive), JavaScript, PHP, MySQL.

## Roles
- admin: full control
- teacher: own classes and marks
- head: view only

## Local setup
1. Install XAMPP and copy this folder into htdocs.
2. Create a MySQL database named school_system and import database/schema.sql.
3. Edit includes/config.php with your database details.
4. Open http://localhost/school-system/
